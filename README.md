# Autonomous Driving Papers 全文日本語訳

原文 PDF と全文日本語訳を、左右（スマホ・タブレット縦では上下）に並べてスクロール同期しながら読むためのサイトです。

- 閲覧: https://takahoribe.github.io/AD-Papers/
- 構成: `papers/<論文>/index.html`（原文と訳文の同期ビューア）、`ja.html`（訳文のみ）、`<論文>.pdf`（原文）、`figs/`（図）
- 論文タイトルと参考文献は原文（英語）のまま掲載しています。
- 翻訳は Claude による機械翻訳です。原文の誤りと思われる箇所には「訳注」を付けています。
- 原文の著作権は各著者・出版社に帰属します。個人の学習目的で整理したものです。
